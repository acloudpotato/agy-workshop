# Build with Google AI — Hands-On Workshop Codelab (`PulseDaily AI`)

An interactive **Google Codelabs-style** workshop application teaching developers how to operate as a **One-Person AI Company** using:
- **Google Antigravity 2.0** (`.agents/skills/*/SKILL.md` Persona Workforce + `GEMINI.md` Lead Orchestrator Memory)
- **Google Stitch & `StitchMCP`** (Reference-Driven UI Design anchored to `news.google.com` Material Design 3)
- **Google AI Studio Build Mode (`ai.studio/build`)** (Gemini `@google/genai` with strict `Type.OBJECT` `responseSchema`, Google SSO Gmail Login + Persona Selection, and Breaking News Alerts)
- **Google Cloud Run (Starter Tier)** (Zero-billing 1-click serverless deployment)

## 🚀 Run Locally

```bash
git clone https://github.com/acloudpotato/agy-workshop.git
cd agy-workshop
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
